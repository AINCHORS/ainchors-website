# Content source policy

The authoritative content sources are `https://www.ainchors.com` and the read-only legacy mirror at `C:\xampp\htdocs\ainchors-website`.

Text, company details, trainer information, course descriptions, testimonials, logos, images and icons must be preserved. Laravel V2 owns implementation and presentation only.

The legacy bridge copies the existing static pages into `resources/legacy` so every historic route remains available locally while modules are progressively rebuilt in Blade.
